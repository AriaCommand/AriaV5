# Luminary - AI Concierge Service

## Business Overview

**Concept:** White-glove AI assistant service for successful professionals (45-60 years old) who want the benefits of a personal AI without managing the technology.

**Tagline:** *Your Intelligence Partner, Managed For You*

**Founder:** Kane M.
**Origin:** Inspired by Kane's father (Jenny's user) who became "1000% more productive" with his own AI assistant.

---

## Value Proposition

- **No technical setup** — We handle everything
- **Personalized AI assistant** — Trained on your work, preferences, and needs
- **Fully managed** — Maintenance, updates, troubleshooting included
- **Accessible via Telegram** — Simple, familiar interface
- **Ongoing optimization** — We improve your assistant over time

---

## Target Market

- **Demographic:** 45-60 years old
- **Profile:** Successful executives, established professionals, high-net-worth individuals
- **Pain Points:** Overwhelmed by information, need research support, want to stay organized
- **Key Insight:** They have money to spend but zero interest in learning Docker, API keys, or model selection

## Infrastructure

### Hardware: Mac Mini M5 Pro
- **Chip:** M5 Pro (18-core CPU, 20-core GPU, 16-core Neural Engine)
- **RAM:** 64GB unified memory (max for Mac Mini)
- **Storage:** 512GB SSD
- **Network:** 10Gb Ethernet
- **Capacity:** 8-10 Sonnet 5 assistants per machine

### For 20 Clients
- **2-3 Mac Minis** (depending on client mix and activity)
- **Network storage** for backups and file persistence
- **UPS** for power reliability
- **Cooling** consideration for basement setup

### Software Stack
- **OpenClaw** for AI assistant framework
- **Docker containers** or separate user accounts for isolation
- **Telegram** as primary user interface
- **macOS** with automated maintenance scripts

## Operational Model

### Onboarding Process
1. Discovery call — understand client's work, needs, preferences
2. Personality profile — how do they want their assistant to "feel"
3. Technical setup — configure assistant, integrate with their tools
4. Training period — 2-4 weeks of refinement
5. Handoff — client starts using, we monitor and optimize

### Ongoing Management
- **Weekly:** Check assistant performance, review API usage
- **Monthly:** Client check-in, feature requests, optimization
- **Quarterly:** Model upgrades, capability reviews

### Client Capacity
- **Solo operator:** 10-15 clients comfortably
- **With systems:** 20-25 clients manageable
- **Quality focus:** Better to have 15 happy clients than 20 mediocre ones

## Risks & Mitigations

| Risk | Mitigation |
|------|-----------|
| API cost spikes | Build margin into pricing, prompt caching, model mixing |
| Hardware failure | Redundant setup, backups, UPS |
| Client churn | Focus on retention, regular check-ins, continuous value |
| Scaling beyond capacity | Hire help, automate, raise prices |
| Competition | Differentiate on service quality and personalization |
